# Abdelrahman Amgad Portfolio Website

This is the first working version of the website.

## Open locally
Double-click `index.html`.

## Free publishing options
- Netlify Drop
- GitHub Pages
- Cloudflare Pages

## Adding projects
Open `script.js` and edit the `projects` array.
Each project can later be expanded into a full standalone case-study page.

## Main files
- `index.html` — website structure and text
- `styles.css` — visual design and responsive layout
- `script.js` — projects and interactions
- `assets/` — profile image and CV
